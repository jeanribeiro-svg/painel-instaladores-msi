# Painel de Instaladores MSI — v8

Versão com navegação funcional entre duas páginas:

- **Dashboard** — indicadores, gráfico, filtros e catálogo.
- **Mídias / Downloads** — links e endereços da aba `Midias` do Google Sheets.

## Google Sheets

Aba `Softwares`:

`Software | Status`

Aba `Midias`:

`Software | Tipo | Link | Observação`

A navegação é feita sem recarregar a página e usa `#dashboard` / `#midias` no endereço. O botão **Ver mídias / downloads →** também abre diretamente a segunda página.

## Publicação

Substitua os arquivos da versão anterior no GitHub Pages. O script desta versão é `script-v8.js`, evitando cache do JavaScript antigo.
